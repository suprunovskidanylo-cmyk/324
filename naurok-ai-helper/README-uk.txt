НА УРОК — AI ПОМІЧНИК (Windows + Tampermonkey + OpenAI API)

ЩО ВМІЄ
- Працює на сторінках naurok.com.ua у невеликій панелі.
- Після натискання кнопки надсилає видиме запитання та знайдені radio/checkbox варіанти до локального сервера.
- Показує пояснення та підсвічує запропоновані варіанти зеленим.
- Не натискає варіанти автоматично і не запускає API-запити без натискання кнопки.

ОБМЕЖЕННЯ
- Сайт може змінювати HTML; автоматичне знаходження запитань не гарантоване на кожному типі завдання.
- Найкраще працює зі звичайними radio/checkbox варіантами. Завдання з картинками, перетягуванням, відкритою відповіддю або спеціальними кастомними кнопками можуть не розпізнаватися.
- Модель може помилятися. Перевіряй пояснення.
- OpenAI API оплачується окремо від підписки ChatGPT.

1. ВСТАНОВИ NODE.JS
Встанови актуальну LTS-версію Node.js з https://nodejs.org/ і відкрий нове вікно PowerShell.
Перевір: node --version

2. СТВОРИ OPENAI API KEY
Створи ключ у панелі OpenAI API: https://platform.openai.com/api-keys
Не вставляй ключ у Tampermonkey або в цей файл. Не передавай його іншим.

3. ЗАДАЙ КЛЮЧ У WINDOWS
Найкраще через інтерфейс Windows:
- Пуск → пошук «Змінні середовища» → «Змінити змінні середовища облікового запису».
- У «Змінні користувача» натисни «Створити».
- Ім’я: OPENAI_API_KEY
- Значення: твій API-ключ.
- Натисни OK і закрий усі вікна PowerShell, якщо вони були відкриті.

Не публікуй ключ і не вставляй його в скрипт браузера.

4. ЗАПУСТИ ЛОКАЛЬНИЙ СЕРВЕР
- Розпакуй папку naurok-ai-helper у постійне місце, наприклад Документи.
- Відкрий цю папку у Провіднику.
- Клацни адресний рядок, введи powershell і натисни Enter.
- Виконай: node .\server.js
Має з’явитися повідомлення про адресу http://127.0.0.1:3219.
Залиш це вікно відкритим, поки користуєшся помічником.

Якщо твій API-проєкт не має доступу до моделі за замовчуванням, задай змінну OPENAI_MODEL назвою моделі, доступної у твоєму акаунті, і перезапусти сервер. Наприклад, у поточному вікні PowerShell:
$env:OPENAI_MODEL="назва-доступної-моделі"
node .\server.js

5. ВСТАНОВИ USERSCRIPT
- Встанови Tampermonkey у Chrome.
- Натисни значок Tampermonkey → Create a new script.
- Видали вміст редактора.
- Відкрий файл naurok-tampermonkey.user.js з цієї папки, скопіюй увесь код і встав у редактор Tampermonkey.
- Натисни Ctrl+S.
- Переконайся, що скрипт увімкнений.

6. ВИКОРИСТАННЯ
- Залиш server.js запущеним.
- Відкрий сторінку завдання на naurok.com.ua.
- Натисни «Проаналізувати видиме запитання» у панелі внизу праворуч.
- Якщо вдалося розпізнати варіанти, запропоновані ШІ підсвітяться зеленим, а пояснення з’явиться в панелі.

УСУНЕННЯ ПРОБЛЕМ
- «OPENAI_API_KEY is not set»: задай змінну середовища та запусти нове вікно PowerShell.
- HTTP 401/invalid_api_key: перевір ключ.
- Model not found / access denied: задай OPENAI_MODEL з назвою моделі, доступної у твоєму API-проєкті.
- «Не знайшов стандартних варіантів»: поточний тип завдання не підтримується автоматичним пошуком. Потрібно адаптувати селектори до актуальної розмітки сайту.
- Якщо Tampermonkey не може підключитися до localhost, перевір, що сервер працює, і дозволь Tampermonkey доступ до запитів на 127.0.0.1, якщо браузер показує такий запит.

БЕЗПЕКА
- Сервер слухає лише 127.0.0.1, а не зовнішні мережеві інтерфейси.
- Не відкривай цей порт у роутері й не змінюй HOST на 0.0.0.0.
- API-ключ зберігається в змінних середовища, а не в браузерному скрипті.
- Запитання та варіанти, які ти надсилаєш, передаються OpenAI API для обробки.
